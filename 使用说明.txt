AI 小助理 —— 使用说明
========================================

一、怎么开始用

1. 把整个「AI小助理」文件夹解压到任意位置（桌面、D 盘都行），
   不要只把 exe 单独拖出来，它旁边的那些文件是必需的。
2. 双击「AI小助理.exe」。

二、第一次打开，需要填两样东西

1. 记忆库目录 —— 你放笔记的地方。
   还没有的话，点「不用选，帮我建一个空的」，会自动按标准目录建好。
2. DeepSeek API Key —— 每个人用自己的一份。
   去 platform.deepseek.com 注册，进「API keys」创建一个，
   复制 sk- 开头的那串，粘进去。
3. 点「开始使用」。

三、日常怎么用

- 中间打字聊天，Enter 发送，Shift+Enter 换行。
- 左边「会话」是历史记录；「记忆库」能翻笔记、搜内容。
- 想让 AI 带着你的笔记回答，先搜关键词，再点「AI 检索问我」。
- 打开一篇笔记后可以「加入对话参考」「编辑」「删除」。
- 右侧显示她当前的心情，以及这一轮用到了哪几篇笔记。
- 你在设置里可以换名字、换性格（贴心 / 元气 / 冷静 / 毒舌）、改人设。

四、数据存在哪

- 设置、聊天记录、备份都在程序目录下的 data 文件夹里。
   整个文件夹拷走，就能把全部数据带走。
- 删笔记不是真删，会移到 data\backups\trash，可以手动找回。
- 改笔记前会自动备份到 data\backups\日期\。
- 07-附件 目录是只读的，不会被改。
- API Key 只存在你自己电脑上，不会上传到任何地方。

五、常见问题

- 打不开 / 窗口空白：装一下「Microsoft Edge WebView2 运行时」。
  Win10 / Win11 一般自带，没有的话在微软官网搜这个名字下载。
- 提示「API Key 无效或已失效」：Key 复制错了，或者已删除，重新建一个。
- 提示「余额不足」：去 DeepSeek 充值，按用量计费，日常聊天很便宜。
- 装在 Program Files 下写不了数据：不用担心，
  程序会自动把数据改放到 %LOCALAPPDATA%\AI小助理。

六、版本更新

作者会不定时发新版本，你有两种方式更新：

1. 程序里自动提示（推荐）
   右上角出现「⬆ 有新版本」就点它，再点「下载并更新」，
   程序会自己下载、覆盖安装、重新打开。
   你的设置、密钥、聊天记录、笔记备份都在 data 目录里，更新不会动它们。

2. 手动覆盖
   拿到新的压缩包后，**直接解压到原来的文件夹，覆盖同名文件**就行。
   同样不会影响 data 目录里的个人数据。

如果点「下载并更新」报错，多半是网络连不上更新源，
那就让作者直接把新压缩包发给你，用第二种方式覆盖即可。
